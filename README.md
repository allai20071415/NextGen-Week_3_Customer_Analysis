# NextGen-Week_3_Customer_Analysis
# Week 3 – Statistics and Customer Analysis

## Internship

**Data Analytics Internship – Next Gen Software Hub Pvt. Ltd.**

## Overview

Week 3 focused on applying statistical methods to analyze customer data and generate business insights.

The main topics covered were descriptive and inferential statistics, hypothesis testing, correlation analysis, regression analysis, and customer analysis.

## Topics Covered

- Descriptive Statistics
- Inferential Statistics
- Hypothesis Testing
- Correlation Analysis
- Regression Analysis
- Customer Analysis
- Business Insights

## Project – Customer Analysis for Business Insights

The project analyzes customer information to understand customer behavior and identify useful business insights.

The analysis includes customer-level data and variables such as:

- Customer information
- Customer visits
- Monthly spending
- Customer-related analysis variables

**Note:** The dataset used for this project is a synthetic/practice dataset because an official company dataset was not provided.

## Descriptive Statistics

Descriptive statistical measures were calculated to understand the distribution of the customer data.

The analysis includes:

- Mean
- Median
- Standard Deviation
- Minimum
- Maximum
- First Quartile (Q1)
- Third Quartile (Q3)

## Hypothesis Testing

A hypothesis test was performed to evaluate a statistical assumption using the customer data.

The analysis includes:

- Null Hypothesis (H₀)
- Alternative Hypothesis (H₁)
- Test Statistic
- p-value
- Decision based on the selected significance level

## Correlation Analysis

Correlation analysis was used to examine the relationship between customer-related numerical variables.

This helps understand whether changes in one variable are associated with changes in another variable.

## Regression Analysis

Regression analysis was performed to study the relationship between:

- **Monthly Spend**
- **Visits per Month**

The analysis includes the regression relationship and **R² (R-squared)** value.

## Customer Segmentation

Customers were grouped into different value segments based on their spending:

- Low Value
- Medium Value
- High Value

This segmentation helps understand differences among customers and supports business-oriented analysis.
